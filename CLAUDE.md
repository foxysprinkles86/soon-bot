- AI: **DeepSeek** `deepseek-chat` (OpenAI-compatible, JSON mode). Monthly cap **$10** (`AI_MONTHLY_CAP_USD`); falls back to canned lines when over. 25s timeout, one quick retry for blips (`Brain._post`), max_tokens 450 (220 could cut long replies off → garbled JSON → backup line). When it fails: direct messages get a FALLBACK line (e.g. "I heard you. I'm choosing not to process it."), maybe/butt-in messages get silence ("typing" then nothing). **Backup AI brain** (Shannon's call, after a DeepSeek slowdown on Oct 14): settings `BACKUP_API_KEY` (she pastes it in Railway herself), `BACKUP_BASE_URL` (default OpenRouter), `BACKUP_MODEL` (comma list sent as OpenRouter `models` fallbacks, default `deepseek/deepseek-chat,deepseek/deepseek-chat-v3-0324,openai/gpt-4o-mini`; a 429 "too busy" also gets one retry; backup temperature capped at `BACKUP_TEMPERATURE` 0.7 because DeepSeek's API secretly scales temperature down and other hosts don't: raw 1.1 = word salad), `PRIMARY_TIMEOUT` (8s).
